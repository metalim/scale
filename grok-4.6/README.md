# SCALE

Интерактивный логарифмический зум от кварков до наблюдаемой Вселенной.

**Демо:** https://metalim.github.io/scale/

Объекты реально растут и уменьшаются с камерой. На каждом уровне свой векторный объект. Одна общая скорость времени — только от текущего зума.

Колёсико / слайдер / `+` `−` · пробел — пауза · `T` — тур · `0` — к 1 м.

Локально: открыть `index.html` или `python3 -m http.server`.
